---

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite 8
- **Smooth Scrolling & Motion**: Lenis Scroll + GSAP (GreenSock)
- **Icons**: Lucide React
- **Linter**: Oxlint
- **Styling**: Vanilla CSS with modern CSS custom properties and tokens

---

## 💻 Local Development & Building

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Local Development Server**:
   ```bash
   npm run dev
   ```

3. **Build Production Bundle**:
   ```bash
   npm run build
   ```
   *Build verification status: Verified locally (Vite production bundle successfully builds with zero errors).*

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```
